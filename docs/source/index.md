# Rad-Cal Tool

``rad-cal`` is the Aresys' radiometric re-calibration tool for Sentinel-1 L1 products.

# Corrections

3 different corrections are available:

- Absolute calibration constant correction
- Processing gain correction
- Elevation antenna pattern gain correction

The software computes and applies the selected corrections and writes on disk the re-calibrated product raster.
